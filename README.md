# Moto Trials (рабочее название)

2D мотокросс-игра с физикой в духе Mad Skills Motocross. Платформы: веб и Android (через Capacitor).

Играть: https://novokshonovpv.github.io/gggame/ — обновляется автоматически при каждом пуше в `main` (`.github/workflows/pages.yml`).

Стек: TypeScript + Vite, физика Planck.js (Box2D), 3D-графика three.js (запасной 2D-рендер на Canvas: `?2d` в адресе).

## Команды

```bash
npm install
npm run dev          # игра на http://localhost:5173
npm run build        # проверка типов + сборка в dist/
npm run build:share  # одна страница dist/share.html для публикации ссылкой
node tools/sim.ts    # прогон трасс автопилотом без браузера
node tools/feel.ts   # стандартные манёвры для настройки физики
node tools/race.ts   # полная гонка с соперниками без браузера (баланс)
```

Управление: ↑ газ, ↓ тормоз, ← → наклон, R заново, Esc меню. На телефоне — экранные кнопки.

## Мотоциклы, уровни, награды и очки

- Классы: 125 «Шмель» (1 200), 250 BSE T5 (стартовый), 300 «Буран» (8 000), 450 «Зверь» (20 000).
  Соперники всегда едут на том же классе.
- Уровни на каждой трассе: Железо → Бронза → Серебро → Золото → Профи. Следующий уровень открывается
  победой на предыдущем. На каждом уровне 5 заданий (место, время и три трюка), каждое даёт звезду.
- Монеты за заезд: место 100/60/40/20, новая звезда 40, первая победа на уровне 150, личный рекорд 20;
  всё × уровень (1 / 1,6 / 2,5 / 4 / 6) × класс (0,9 / 1 / 1,15 / 1,3). Расчёт — в `src/catalog.ts`.
- Очки (общий зачёт): за лучшее место на каждой трассе × уровне × классе 100/60/40/25 × уровень
  (1 / 2 / 3,5 / 5,5 / 8) × класс (0,9 / 1 / 1,2 / 1,4), плюс 10 × уровень за каждую звезду.
- Баланс уровней: `node tools/race.ts [seed] [stock|max] [класс]`, эталонные времена: `node tools/pars.ts`.

## Сервер: облачное сохранение, ники и таблицы рекордов (Firebase)

Игроки входят анонимно (ник, рекорды и сохранение работают без Google); кнопки «Войти через Google» у них нет —
она появляется только по адресу с `?login` (например, https://novokshonovpv.github.io/gggame/?login).

Пока в `src/cloud-config.ts` стоит `null`, игра работает без сервера: ник и рекорды хранятся только
на устройстве, общие таблицы не видны. Чтобы включить:

1. https://console.firebase.google.com → «Создать проект» (Google Analytics не нужен).
2. Build → Authentication → Get started → Sign-in method: включить **Google** и **Anonymous**
   (анонимный вход нужен, чтобы ник и рекорды работали без входа через Google).
3. Authentication → Settings → Authorized domains → добавить `novokshonovpv.github.io`.
4. Build → Firestore Database → Create database (production mode, регион `eur3`).
5. Firestore → Rules → вставить содержимое `firestore.rules` → Publish.
6. Project settings → Your apps → Web (`</>`) → зарегистрировать приложение и скопировать `firebaseConfig`
   в `src/cloud-config.ts`.
7. Модератор (право удалять ники): войти в игру через Google, затем в консоли Authentication → Users
   скопировать свой User UID, в Firestore создать коллекцию `admins` и документ с этим UID (поля не нужны).
   После перезапуска игры в таблицах рекордов рядом с чужими никами появится кнопка ✕.

Данные: `users/{uid}` — прогресс, `users/{uid}/ghosts/{trackId}` — призраки, `players/{uid}` — ник и очки,
`nicks/{ник}` — кому принадлежит ник, `boards/{трасса_уровень_класс}/times/{uid}` — лучшие времена.
Удалённый модератором ник остаётся заблокированным, игрок пропадает из таблиц и выбирает новый.
Объединение прогресса с разных устройств — `src/progress.ts` (проверка: `node tools/merge-test.ts`).
## Структура

- `src/bike.ts` — физика байка, все параметры «ощущения» в объекте `BIKE`
- `src/track.ts` — конструктор трасс из MX-элементов (столы, дабблы, роллеры, ступени) и сами трассы
- `src/render3d.ts` — 3D-сцена: объёмная трасса, байки и гонщики из 3D-деталей, тени, фон из планов
- `src/render.ts` — 2D-отрисовка (запасной вариант) трассы (объёмная полоса, срез грунта, забор), байка и гонщика
- `src/scenery.ts` — темы 13 трасс-городов и параллакс-фоны; `src/landmarks.ts` — силуэты достопримечательностей (только светские)
- `src/dust.ts` — пыль из-под колёс при разгоне и на приземлениях (общая для 3D и 2D)
- `src/bikeShape.ts` — геометрия BSE T5 по фото из каталога 67moto (общая для 3D и 2D)
- `src/fullscreen.ts` — полный экран на телефоне и подсказка по установке на главный экран
- `src/race.ts` — гонка: соперники, круги, респавн после падения, позиции
- `src/cloud.ts`, `src/progress.ts` — сервер: вход, ники, таблицы рекордов, модерация, облачное сохранение
- `src/ghost.ts` — призрак рекорда: запись позы байка 30 раз в секунду, сохранение и воспроизведение
- `src/audio.ts` — весь звук синтезом (Web Audio): моторы с передачами, приземления, падения, сигналы, музыка
- `src/catalog.ts` — мотоциклы и классы, уровни сложности, покраска, экипировка, экономика и очки
- `src/garage.ts` — профиль игрока: монеты, мотоциклы, прокачка, покраска, экипировка, ник
- `src/missions.ts` — 5 заданий на трассу и уровень (место, время, вилли, бэк- и фронтфлипы, полёт, скорость, без падений)
- `src/ai.ts` — автопилот, на нём ездят соперники
- `src/main.ts` — игровой цикл, состояния, интерфейс
