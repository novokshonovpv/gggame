# Moto Trials (рабочее название)

2D мотокросс-игра с физикой в духе Mad Skills Motocross. Платформы: веб и Android (через Capacitor).

Играть: https://novokshonovpv.github.io/gggame/ — обновляется автоматически при каждом пуше в `main` (`.github/workflows/pages.yml`).

Стек: TypeScript + Vite, физика Planck.js (Box2D), 3D-графика three.js (запасной 2D-рендер на Canvas: `?2d` в адресе).

## Команды

```bash
npm install
npm run dev          # игра на http://localhost:5173
npm run build        # проверка типов + сборка в dist/
npm run build:share  # одна страница dist/share.html для публикации ссылкой
node tools/sim.ts    # прогон трасс автопилотом без браузера
node tools/feel.ts   # стандартные манёвры для настройки физики
node tools/race.ts   # полная гонка с соперниками без браузера (баланс)
```

Управление: ↑ газ, ↓ тормоз, ← → наклон, R заново, Esc меню, M — звук вкл/выкл. На телефоне —
экранные кнопки; кнопка с динамиком (в меню, в заезде и в открытом мире) выключает весь звук.

## Гараж в стиле 67МОТО

Главное меню стоит в 3D-копии мотосалона 67МОТО (Смоленск): плиточный пол, стена с вывеской BSE,
тёмная каменная стена с логотипом, лайтбоксы с фотографиями салона и ряд мотоциклов. Экран «Гараж»
оформлен как сайт салона (шрифты Manrope и Unbounded, бежевый акцент, карточки с фото из каталога).
Фото, логотипы и шрифты взяты из проекта сайта 67moto и лежат в `src/assets/67moto/`.

## Открытый мир

Пока скрыт: управление требует доработки. Кнопка `#hub-open` в `index.html` спрятана классом
`hidden` — убрать его, чтобы вернуть режим. Свободная езда по лесу 640 × 640 м и эндуро-стадиону.
Код в `src/open/` (загружается только при входе в режим):

- `bike3d.ts` — физика мотоцикла поверх твёрдого тела Rapier, как у настоящего:
  - колёса — профиль шины, который «опускается» по ходу подвески (shape cast), поэтому бревно
    встречает передняя часть покрышки; пружина с преднатягом, прогрессивный отбой в конце
    300 мм хода, раздельные сжатие и отбой, ноги гонщика гасят удары сильнее ~2,5 g;
  - шины: проскальзывание из собственного вращения колеса, угол увода, развал от наклона,
    общий круг трения (пробуксовка срывает зад в занос, блокировка тоже), сцепление и
    сопротивление качению по покрытию (грунт, трава, грязь, доски моста);
  - двигатель: кривая момента, 6 передач с автоматом, сцепление при трогании, торможение
    двигателем, отсечка; реакция маховика и колеса на раму (газ в воздухе поднимает нос,
    тормоз опускает);
  - управление креном: игрок задаёт наклон, руль сам контррулит и держит поворот; на малой
    скорости — прямое руление и балансирование;
  - падения: шлем коснулся чего-то, сильный удар, мотоцикл лёг, жёсткое приземление;
- `world.ts` — мир: рельеф (коллайдер — heightfield), река, лесная тропа 1,8 км с мостами и
  трамплинами, ели и берёзы (карточки веток с альфой, чанки 4 × 4), валуны; эндуро-стадион —
  бревна, тракторные шины, стол, каменный сад, ступени из шпал, грязевая яма; вокруг рекламные
  борта, билборды, развевающиеся флаги и арка старта (трибун нет);
- `textures.ts` — процедурные текстуры (трава, грунт, камень, песок, кора, ветки, листья,
  нормали воды, облака, реклама, флаги); `grass.ts` — трава на GPU вокруг камеры;
  `sky.ts` — физическое небо, облака и карта окружения; `fx.ts` — пыль из-под колёс;
- `game.ts` — режим: камера сзади и вид из шлема (C), мини-карта, спидометр с тахометром и
  передачей, заезды по воротам «Эндуро-стадион» (2 круга) и «Лесной маршрут», кнопки на телефоне.

Управление: W/↑ газ, S/↓ тормоз (стоя на месте — откатиться назад), Пробел — задний тормоз
(занос), A/D или ←/→ — наклон в поворот, C — камера, R — на ноги, Esc — пауза.

Проверки без браузера: `node tools/open-sim.ts` (разгон, тормоз, повороты с контррулением,
бревно, секция бревен, трамплин, занос) и `node tools/open-trace.ts <gas|turn|log|logs|ramp|slide>`.

## Город 67 (вид сверху, встраивается на сайт)

Главное меню: анимированный логотип «ГОРОД 67», имя игрока (общий ник с Moto Trials, Firebase),
три слота сохранений (`localStorage`, `moto-city-slot-1..3`; старое сохранение переносится в
слот 1), онлайн-таблицы «Заработано всего» и «Круг на Эндуро-арене» (`boards/city67_money` и
`boards/city67_lap` — значение лежит в поле `time`, как требуют текущие `firestore.rules`),
выбор цвета шлема и куртки, настройки, управление, титры. Клавиатура ↑ ↓ Enter, мышь, тач.
Код: `src/city/menu.ts`, `saves.ts`, `cloud.ts` (Firebase SDK грузится только при входе).

Навигатор: на карте города (Tab или клик по мини-карте) нажми на точку — по улицам строится
маршрут (A* по клеткам: дороги дешевле тротуаров и газонов, `CityMap.route`), он рисуется на
асфальте, на мини-карте и на карте, стрелка у героя показывает поворот, в углу — расстояние
(«📍 850 м ✕», нажатие сбрасывает). Свернул — маршрут перестраивается, приехал — выключается.
Код: `src/city/nav.ts`.

На Эндуро-арене шины и камни проезжаются, но медленно (~20 км/ч) и с подбросом.

### Онлайн

Все игроки в одном городе: видны их байки и герои с никами (на мини-карте — голубые точки),
выстрелы, ракеты; байки толкаются. PvP: попадания и тараны по игрокам работают, если PvP
включено у обоих (Настройки → «Стрельба по игрокам», по умолчанию вкл.), урон по игрокам вдвое
меньше, после возрождения 5 с защиты; «X сбил Y» видят все рядом. Чат — T (или кнопка 💬): до
80 символов, раз в 2 с; мат заменяется звёздочками при отправке и ещё раз при показе
(`src/city/censor.ts`), тот же фильтр не пускает матерные ники. Машины, пешеходы и полиция у
каждого свои — общие только игроки.

Сеть — Firebase Realtime Database (`src/city/net.ts`, `online.ts`): позиция 8 раз в секунду
(стоя — раз в секунду) в участок `city67/pos/{участок 2048×2048}/{uid}`, слушаются только 3×3
участка вокруг; события (выстрелы, попадания, круги) живут 5 с, чат — 2 мин. Бесплатный тариф —
до 100 игроков одновременно. `?net=local` — мультиплеер между вкладками одного браузера (для
проверки), `?net=off` — без сети.

**Включить (один раз, в консоли Firebase проекта moto-aaf82):**
1. Build → Realtime Database → Create database → регион **Belgium (europe-west1)** → «Start in
   locked mode».
2. Вкладка Rules → вставить содержимое `database.rules.json` → Publish.
3. Если выбран другой регион — вписать адрес базы в `CITY_RTDB_URL` (`src/cloud-config.ts`).

Пока база не создана, игра работает одна, в углу — «Офлайн».

Реклама: щиты с логотипами брендов из каталога 67МОТО на крышах (BSE — три щита, остальные по
одному: OXO, LEATT, Acerbis, KAYO, Regulmoto, PROGASI, DAYUN, Motoland, MOTUL, Shark, ROQVI, FX MOTO,
ZUUMAV, Ajerra, BENDA) и четыре на заборе арены. Щиты стоят только на высотках (выше 4,5 клетки),
которые выше всех домов вокруг, — так их не перекрывают соседние небоскрёбы. Логотипы — файлы сайта 67moto.ru
(`img/site/brands/<id>-color.webp`, лежат в `public/brands`), список — `src/city/brands.ts`. Щит
кликабелен (мышь, касание): открывает подборку бренда, `https://67moto.ru/?brand=<Бренд>#catalog`.

Полиция «попроще»: патрулей меньше, маршрут к игроку обновляется раз в 1,5 с, видят ближе,
стреляют реже и мимо, задерживают дольше, розыск спадает за 8 с вне видимости. Транспорт спокойнее:
максимальная скорость всех мотоциклов и машин ещё на 13 % ниже (BSE Z3 — около 110 км/ч), разгон на 8 % мягче.

Отдельная игра в духе классических городских экшенов с видом сверху, только главный герой —
мотоциклист-курьер 67МОТО на BSE. Логотип, шрифты (Unbounded, Manrope), фото байков и цвета —
от салона 67МОТО: салон и сервис в городе, рекламные щиты на крышах, доставки запчастей. Страница `city.html` (кнопка «Мото-город» в главном меню), играть:
https://novokshonovpv.github.io/gggame/city.html. Сборка лёгкая (~30 КБ gzip, без three.js),
рисуется на Canvas 2D.

- Город генерируется из зерна: 354 × 354 клетки (≈ 1,4 км в поперечнике, ~2 500 домов, 60 улиц),
  сетка улиц с двусторонним движением, кварталы с домами разной высоты (выше к центру, крыши
  «наклоняются» от камеры — псевдо-3D), парки, парковки, две реки с мостами, остров с пляжем.
  5 сервисов, 2 салона, 3 больницы и 3 участка (возрождение — в ближайших), 50 точек заданий.
  Tab или кнопка 🗺 — карта всего города: колесо мыши, два пальца или кнопки +/− — масштаб до ×12, перетаскивание — сдвиг, ◎ — к себе. Дома, деревья и фонари хранятся по участкам 16×16
  клеток, рисуется только видимое. У улиц есть названия, адреса доставки — «ул. … / пр. …».
- Мотоцикл: сцепление шин, занос (Пробел), разгон и тормоз, на газоне и песке медленнее;
  сильный удар выбрасывает гонщика из седла. Пешком можно сесть на любой мотоцикл или в любую
  машину (E) — седан, хэтчбек, такси, фургон, автобус, даже полицейскую (сразу 2 звезды розыска);
  водителя выкидывает. В машине жёсткие удары и пули ранят слабее, из неё не вылетаешь.
- Оружие: человек падает замертво с третьего попадания (первые два — убегает раненым), взрыв
  убивает рядом. Из убитого выпадают его деньги, 100–500 ₽, лежат 30 секунд.
- Трафик ездит по полосам и поворачивает на перекрёстках, тормозит перед препятствиями и
  сигналит; пешеходы ходят по тротуарам, переходят по зебрам, отскакивают от мотоциклов.
- Полиция: звёзды розыска за наезды, угон и тараны; патрули гонятся по карте (поиск пути по
  сетке), таранят, задерживают пешего или стоящего игрока. Розыск спадает, если скрыться из
  виду, или снимается в мотосервисе за деньги (там же ремонт).
- Задания на точках: доставка (зелёные), уличная гонка по 6 точкам (оранжевые), горячий груз
  с розыском (красные). Деньги на улицах, аптечки, машины горят и взрываются.
- Ящики «?» с сюрпризами (как в старых GTA): 5–20 тыс. ₽, бронежилет, нитро ×3 (Shift на
  байке), взятка (снимает розыск), карта «Выйти из участка», двойные деньги на 90 с, ракетница,
  «денежный дождь» (10 монет за 45 с) — или ловушка со взрывом. После находки ящик появляется
  в другом месте через 2 минуты.
- Пешком Shift — бег. Пешком играет фоновая музыка (джаз и грув, тоже Kevin MacLeod:
  «Local Forecast», «Night in Venice», «Groundwork», «Late Night Radio»), R — вкл/выкл.
- Эндуро-арена: квартал 34 × 34 клетки с забором и воротами, трасса из 11 ворот: бревна (байк
  их перепрыгивает на скорости), тракторные шины, камни, две грязевые ямы, «стиральная доска»,
  трамплины. Въезд на старт запускает круг на время, рекорд сохраняется (+10 000 ₽ за новый).
- Прыжки: 35 трамплинов в парках и над реками (через реку можно перелететь). В воздухе ← →
  крутят байк, приземляться нужно ровно. Деньги за трюк растут с временем полёта, 360° — вдвое.
- Телефоны-автоматы (10 по городу): один звонит, подбеги — особое задание: перехватить курьера
  на чёрном спортбайке и отвезти его посылку, взорвать чёрный фургон (ракеты в подарок),
  продержаться 3 минуты с четырьмя звёздами.
- Серия заданий: каждое выполненное подряд добавляет ×0,25 к деньгам (до ×2), сбрасывается
  при «Разбился» и «Задержан». Полицейский вертолёт с четырёх звёзд: следит сверху (ночью —
  прожектор), на пяти звёздах стреляет. 20 секретных посылок (+5 000 ₽, за все — 100 000 ₽).
- Радио на мотоцикле — настоящая музыка: «Мото FM» (рок), «Ночной город» (электроника), «Радио
  Грув» (фанк), по три трека. Станции «в эфире» всё время: переключился — попал в середину
  песни, между станциями шипит эфир. Переключение: R (Shift+R — назад), колесо мыши, стрелки
  ◀ ▶ у названия станции, на телефоне — кнопка 📻. Файлы — `public/radio/*.m4a` (AAC 64 кбит/с,
  выровненная громкость, ~14 МБ), грузятся по частям только во время игры радио.
- Мотор — тот же синтез отдельных вспышек цилиндра, что и в Moto Trials (`src/thumper.ts`): у
  каждого байка свой диапазон оборотов и тембр (одноцилиндровые четырёхтакты, двухтакты,
  чоппер, четырёхцилиндровый спортбайк), коробка с переключениями.
- Оружие из ящиков на улицах: пистолет, автомат, дробовик (огонь вперёд, и с мотоцикла тоже).
  Выстрелы рядом с патрулём добавляют розыск; с трёх звёзд полиция стреляет в ответ; при
  задержании оружие изымают.
- День и ночь: сутки идут 8 минут (час = 20 с), старт в 17:00. Ночью темно: светят фонари, фары,
  мигалки и окна домов, полиция видит хуже. `city.html?night` или `?t=22` — начать в нужный час.
- Деньги в рублях. Доставка — 3 500–7 000 ₽, гонка — 10–15 тыс., горячий груз — 12–20 тыс.,
  пачки на улице — 300–1 500 ₽, бонус 100 ₽ за каждую оставшуюся секунду. Штрафы: больница
  3 000 ₽, залог 4 000 ₽ + 3 000 ₽ за звезду, смена номеров в сервисе — 4 000 ₽ за звезду.
- Салон 67МОТО: BSE Z3 250 (стартовый), EX 125 — 45 000 ₽, T5 300 — 180 000 ₽, 2T 300 —
  350 000 ₽. Чужие скутеры, чопперы и спортбайки можно угнать, но не купить. Деньги, байки и
  патроны сохраняются в браузере (`localStorage`, ключ `moto-city-v2`; доллары из первой версии
  переносятся ×50).

Музыка: Kevin MacLeod (incompetech.com), лицензия Creative Commons: By Attribution 4.0

Перекодированы в AAC и выровнены по громкости. В игре автор указан на стартовом экране, в паузе и

Управление: W/↑ газ, S/↓ тормоз и задний ход, A/D или ←/→ руль, Пробел — занос (пешком —
удар), Shift — бег (на байке — нитро), E — сесть/слезть, Ctrl / J / левая кнопка мыши — огонь,
Q — сменить оружие, R / колесо мыши — радио, Tab — карта, Esc — пауза, M — звук. На телефоне — экранные кнопки («Огонь» появляется с оружием, тап по названию
оружия меняет его).

### Как встроить на сайт

```html
<iframe src="https://novokshonovpv.github.io/gggame/city.html"
        width="960" height="540" style="border:0; max-width:100%; aspect-ratio:16/9"
        allow="fullscreen; autoplay" allowfullscreen></iframe>
```

Игра подстраивается под размер рамки, ставится на паузу, когда фокус уходит со страницы,
и не прокручивает сайт стрелками. Внутри iframe нет ссылки «в главное меню». Страница-хозяин
может управлять паузой: `iframe.contentWindow.postMessage({ type: "moto-city:pause" }, "*")`
(и `moto-city:resume`).

## Android (APK)

Приложение для Android собирается автоматически на GitHub при каждом пуше в `main`
(`.github/workflows/android.yml`): Actions → «Android APK» → последний запуск → Artifacts →
`moto-trials-apk`. Это debug-APK: ставится на телефон напрямую (нужно разрешить установку из
неизвестных источников). Обёртка — Capacitor (`capacitor.config.json`, папка `android/`):
альбомная ориентация, игра на весь экран без системных панелей.

Локально (нужны JDK 21 и Android SDK): `npm run build && npx cap sync android`, затем
`cd android && ./gradlew assembleDebug`.

## Мотоциклы, уровни, награды и очки

- Мотоциклы: BSE EX 125 (1 200), BSE Z3 250 (стартовый), BSE T5 300 (8 000), BSE 2T 300 (20 000, класс «300 2T»;
  в коде и сохранениях его ключ — "450").
  Соперники всегда едут на том же классе.
- Уровни на каждой трассе: Железо → Бронза → Серебро → Золото → Профи. Следующий уровень открывается
  победой на предыдущем. На каждом уровне 5 заданий (место, время и три трюка), каждое даёт звезду.
- Монеты за заезд: место 100/60/40/20, новая звезда 40, первая победа на уровне 150, личный рекорд 20;
  всё × уровень (1 / 1,6 / 2,5 / 4 / 6) × класс (0,9 / 1 / 1,15 / 1,3). Расчёт — в `src/catalog.ts`.
- Очки (общий зачёт): за лучшее место на каждой трассе × уровне × классе 100/60/40/25 × уровень
  (1 / 2 / 3,5 / 5,5 / 8) × класс (0,9 / 1 / 1,2 / 1,4), плюс 10 × уровень за каждую звезду.
- Баланс уровней: `node tools/race.ts [seed] [stock|max] [класс]`, эталонные времена: `node tools/pars.ts`.

## Сервер: облачное сохранение, ники и таблицы рекордов (Firebase)

Игроки входят анонимно (ник, рекорды и сохранение работают без Google); кнопки «Войти через Google» у них нет —
она появляется только по адресу с `?login` (например, https://novokshonovpv.github.io/gggame/?login).

Пока в `src/cloud-config.ts` стоит `null`, игра работает без сервера: ник и рекорды хранятся только
на устройстве, общие таблицы не видны. Чтобы включить:

1. https://console.firebase.google.com → «Создать проект» (Google Analytics не нужен).
2. Build → Authentication → Get started → Sign-in method: включить **Google** и **Anonymous**
   (анонимный вход нужен, чтобы ник и рекорды работали без входа через Google).
3. Authentication → Settings → Authorized domains → добавить `novokshonovpv.github.io`.
4. Build → Firestore Database → Create database (production mode, регион `eur3`).
5. Firestore → Rules → вставить содержимое `firestore.rules` → Publish.
6. Project settings → Your apps → Web (`</>`) → зарегистрировать приложение и скопировать `firebaseConfig`
   в `src/cloud-config.ts`.
7. Модератор (право удалять ники): войти в игру через Google, затем в консоли Authentication → Users
   скопировать свой User UID, в Firestore создать коллекцию `admins` и документ с этим UID (поля не нужны).
   После перезапуска игры в таблицах рекордов рядом с чужими никами появится кнопка ✕.

Данные: `users/{uid}` — прогресс, `users/{uid}/ghosts/{trackId}` — призраки, `players/{uid}` — ник и очки,
`nicks/{ник}` — кому принадлежит ник, `boards/{трасса_уровень_класс}/times/{uid}` — лучшие времена.
Удалённый модератором ник остаётся заблокированным, игрок пропадает из таблиц и выбирает новый.
Объединение прогресса с разных устройств — `src/progress.ts` (проверка: `node tools/merge-test.ts`).
## Структура

- `src/bike.ts` — физика байка, все параметры «ощущения» в объекте `BIKE`
- `src/track.ts` — конструктор трасс из MX-элементов (столы, дабблы, роллеры, ступени) и сами трассы
- `src/render3d.ts` — 3D-сцена: объёмная трасса, байки и гонщики из 3D-деталей, тени, фон из планов
- `src/render.ts` — 2D-отрисовка (запасной вариант) трассы (объёмная полоса, срез грунта, забор), байка и гонщика
- `src/scenery.ts` — темы 13 трасс-городов и параллакс-фоны; `src/landmarks.ts` — силуэты достопримечательностей (только светские)
- `src/dust.ts` — пыль из-под колёс при разгоне и на приземлениях (общая для 3D и 2D)
- `src/bikeShape.ts` — геометрия BSE T5 по фото из каталога 67moto (общая для 3D и 2D)
- `src/fullscreen.ts` — полный экран на телефоне и подсказка по установке на главный экран
- `src/race.ts` — гонка: соперники, круги, респавн после падения, позиции
- `src/cloud.ts`, `src/progress.ts` — сервер: вход, ники, таблицы рекордов, модерация, облачное сохранение
- `src/ghost.ts` — призрак рекорда: запись позы байка 30 раз в секунду, сохранение и воспроизведение
- `src/audio.ts` — весь звук синтезом (Web Audio): моторы с передачами, приземления, падения, сигналы, музыка
- `src/catalog.ts` — мотоциклы и классы, уровни сложности, покраска, экипировка, экономика и очки
- `src/garage.ts` — профиль игрока: монеты, мотоциклы, прокачка, покраска, экипировка, ник
- `src/missions.ts` — 5 заданий на трассу и уровень (место, время, вилли, бэк- и фронтфлипы, полёт, скорость, без падений)
- `src/ai.ts` — автопилот, на нём ездят соперники
- `src/open/` — режим «Открытый мир» (см. выше)
- `src/city/` — «Мото-город», отдельная страница `city.html` (см. выше)
- `src/main.ts` — игровой цикл, состояния, интерфейс
